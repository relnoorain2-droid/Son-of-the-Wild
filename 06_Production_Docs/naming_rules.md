# Naming Rules

- C = main character.
- S = supporting character.
- V = variant of an existing character.
- K = creature or animal.
- L = location.
- FULL = full body, head to toe, front-facing.
- FACE = close-up portrait, face and shoulders, front-facing.
- Save names exactly as written in manifests.
- Do not merge identities or rename characters after approval.
