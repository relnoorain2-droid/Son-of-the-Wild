# Hindi Version Reels 9:16 - FROST: Son of the Wild

This folder is separate from the English Reels package.

Use this folder for Hindi vertical Reels/TikTok/Facebook videos.

## Folder Contents

- `Prompts_9x16_Hindi/` - all 312 Dola-ready prompts for Hindi 9:16 output.
- `Skill/SKILL.md` - Hindi Reels skill file to upload in Dola.
- `Production_Docs/` - Hindi output rules.

## Hindi Output Rule

The prompt instructions can stay in English, but Dola must generate the video output in Hindi:

- Hindi spoken dialogue
- Hindi narrator voice
- Hindi lip-sync
- Hindi title cards and location/time cards in Devanagari
- Hindi captions after download

Character names and place names can remain as names.
