# YouTube Movie Package - FROST: Son of the Wild

This folder is separate from the vertical Reels/Facebook prompt package.

Use this folder for YouTube movie generation only.

## Folder Contents

- `Prompts_16x9/` - all 312 Dola-ready prompts converted for YouTube landscape 16:9.
- `Skill/SKILL.md` - YouTube-specific Dola skill. Upload this skill in Dola before using these prompts.
- `Production_Docs/` - notes for YouTube generation and framing.

## Correct Dola Setup

- Model: Seedance 2.5
- Duration: exactly 30 seconds
- Aspect ratio: widescreen 16:9
- Target composition: 1920x1080 landscape
- Use raw GitHub image URLs already included in each prompt.

## Do Not Mix

- For Facebook/Reels/TikTok, use `09_Dola_Ready_Prompts_URL` and the main `Skill/SKILL.md`.
- For YouTube, use only this `YouTube movie` folder and this folder's `Skill/SKILL.md`.
